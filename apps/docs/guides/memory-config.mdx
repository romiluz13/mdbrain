## Required runtime variables

| Variable | Description | Default |
|----------|-------------|---------|
| `MDBRAIN_WIKI_MONGODB_URI` | Transaction-capable MongoDB URI for MDBrain-owned wiki collections | required |
| `MEMONGO_API_URL` | Compatible Memongo HTTP base URL | required |
| `MEMONGO_API_KEY` | Memongo tenant API key | required |
| `MDBRAIN_API_KEY` | Bearer token for MDBrain clients | none |

## Optional variables

| Variable | Description | Default |
|----------|-------------|---------|
| `MDBRAIN_WIKI_DATABASE` | Wiki database name | `mdbrain_wiki` |
| `MDBRAIN_WIKI_COLLECTION_PREFIX` | Wiki collection prefix | `mdbrain_` |
| `MDBRAIN_DELIVERY_RECONCILE_MS` | Durable delivery reconciliation interval | `5000` |
| `MEMONGO_CONTROL_API_KEY` | Separate Memongo control-plane key | none |
| `MEMONGO_TIMEOUT_MS` | Upstream request timeout | `10000` |
| `MEMONGO_COMPATIBILITY_TTL_MS` | Compatibility-check cache duration | `60000` |
| `MEMONGO_ALLOW_INSECURE_LOCAL` | Allow local HTTP when set to `1` | disabled |
| `MDBRAIN_API_PORT` | API listen port | `3847` |
| `MDBRAIN_API_HOST` | API bind address | `127.0.0.1` |

MDBrain fails readiness when Memongo is unavailable or its contract version or
SHA-256 differs from the pinned contract. The wiki store fails closed when
transactions are unavailable.
