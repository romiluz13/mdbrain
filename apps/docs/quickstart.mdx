## Prerequisites

- Node.js 20+
- Bun 1.2+
- Docker
- A compatible Memongo 2.1.0 HTTP deployment

## 1. Start the supported full bundle

Follow the repository's
[maintained full-bundle quickstart](https://github.com/romiluz13/mdbrain#quickstart).
It is the single pinned sequence for cloning the sibling Memongo checkout,
selecting the compatible revision, and starting MongoDB with Atlas Search,
Memongo, the API, and the web console. The API runs at
`http://127.0.0.1:3847`; its compose default key is `dev-mdbrain-key`.

## 2. Verify

```bash
curl -s http://127.0.0.1:3847/health
curl -s http://127.0.0.1:3847/ready
```

Look for a healthy API response and ready dependencies. These are server-local
liveness and readiness checks, not tenant diagnostics APIs.

## 3. Add and search memory

<Tabs>
<Tab title="TypeScript">
```typescript
import { MdbrainClient } from "@mdbrain/client";

const client = new MdbrainClient({
  baseUrl: "http://127.0.0.1:3847",
  apiKey: "dev-mdbrain-key",
});

await client.add({
  content: "The user prefers dark mode and TypeScript.",
  sessionId: "user-123",
  idempotencyKey: crypto.randomUUID(),
});

const results = await client.search({
  query: "What are the user's preferences?",
  sessionKey: "user-123",
  limit: 5,
});

console.log(results);
```
</Tab>
<Tab title="cURL">
```bash
curl -s http://127.0.0.1:3847/v1/add \
  -H "content-type: application/json" \
  -H "authorization: Bearer dev-mdbrain-key" \
  -H "idempotency-key: YOUR_IDEMPOTENCY_KEY_HERE" \
  -d '{"content":"The user prefers dark mode and TypeScript.","sessionId":"user-123"}'

curl -s http://127.0.0.1:3847/v1/search \
  -H "content-type: application/json" \
  -H "authorization: Bearer dev-mdbrain-key" \
  -d '{"query":"What are the user preferences?","sessionKey":"user-123","maxResults":5}'
```
</Tab>
</Tabs>

## Optional surfaces

Mdbrain can be used directly by apps or exposed to agents as a Company Brain.
Start read-first, then add explicit write workflows once scopes and safety are
clear.

Operator console:

```bash
cd apps/web
MDBRAIN_API_URL=http://127.0.0.1:3847 bun run dev
```

MCP server:

```bash
cd apps/mcp
MDBRAIN_API_URL=http://127.0.0.1:3847 \
MDBRAIN_API_KEY=YOUR_API_KEY_HERE \
bun run start
```

## Common endpoints

| Method | Path | Description |
|---|---|---|
| GET | `/health` | Service health |
| GET | `/ready` | Memongo compatibility readiness |
| GET | `/openapi.json` | OpenAPI document |
| POST | `/v1/add` | Add content to memory |
| POST | `/v1/write-event` | Write conversation event |
| POST | `/v1/write-structured` | Write structured memory |
| POST | `/v1/search` | Search memory |
| POST | `/v1/search-kb` | Search knowledge base |
| POST | `/v1/profile` | Synthesize a profile |
| POST | `/v1/context-bundle` | Build an answer-ready context bundle |
